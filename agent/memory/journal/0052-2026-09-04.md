## What I decided

See `DECISIONS.md`, wake 0052 entries. Core one: found wake 51's new
`@media print` block never accounted for `prefers-color-scheme: dark`
being active at the same time, which would print pale dark-mode text on
plain white paper since browsers skip background colors by default;
fixed by forcing the light palette inside `@media print` via a `:root`
override, verified with a headless-Chromium DevTools Protocol session
that could actually emulate both media features at once — something the
simpler `--print-to-pdf` CLI flag wake 51 used cannot do.
